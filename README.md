## Featured Projects

### 1. Perceptra — Agentic RAG & Document Intelligence Platform

**Flagship AI engineering project**

Building a document intelligence application that combines retrieval, agent orchestration, and LLM-powered question answering.

* Orchestrates retrieval and response workflows with LangGraph.
* Integrates Qdrant and Jina AI components for vector retrieval and context construction.
* Uses modular FastAPI components for application and API workflows.
* Incorporates RAGAS, NeMo Guardrails, and observability tooling for evaluation and debugging.
* Includes a Streamlit interface and Docker-based development, with AWS deployment work.

**Stack:** Python · FastAPI · LangGraph · Qdrant · Jina AI · PostgreSQL · Redis · RAGAS · NeMo Guardrails · LangSmith · Logfire · Prometheus · AWS · Docker

🔗 [Repository](https://github.com/Sunny914/Perceptra) · [Portfolio](https://sunny-ai-portfolio-beta.vercel.app/)

### 2. ProductIQ — AI Fashion Search & Recommendation Engine

An AI-powered search and recommendation system designed for natural-language product discovery across a catalog of **367K+ products**.

* Implements BGE embedding-based semantic retrieval and BM25 lexical search.
* Combines retrieval candidates with Reciprocal Rank Fusion (RRF).
* Supports metadata filtering, feature-based ranking, and recommendation diversity.
* Integrates search workflows with FastAPI and Next.js.

**Stack:** Python · PyTorch · Transformers · Sentence Transformers · PostgreSQL · pgvector · BM25 · LightGBM · FastAPI · Next.js · Docker

🔗 [Repository](https://github.com/Sunny914/StyleIQ-AI-Fashion-Search)

### 3. Research Paper Classification Using Graph Convolutional Networks

A graph-learning project that uses paper features and citation relationships for research-paper classification.

* Represents papers as graph nodes and citations as edges.
* Implements a Graph Convolutional Network using PyTorch Geometric.
* Builds preprocessing, training, and evaluation workflows.
* Compares graph-learning performance with conventional ML baselines.

**Stack:** Python · PyTorch · PyTorch Geometric · NumPy · scikit-learn

🔗 [Repository](https://github.com/Sunny914/Research-Paper-Classification-using-Graph-Convolutional-Networks)
