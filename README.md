## 🚀 Featured Projects

### 1. 🔬 Perceptra — Agentic RAG & Document Intelligence Platform

**My flagship AI engineering project**

Building an AI application for document retrieval and evidence-grounded question answering, combining retrieval pipelines, agent orchestration, and LLM application engineering.

**Key engineering areas:**

* Agentic workflows orchestrated using LangGraph
* Vector retrieval with Qdrant and Jina AI components
* FastAPI backend and configurable AI integrations
* Evaluation and guardrail tooling with RAGAS and NeMo Guardrails
* Observability with Logfire, LangSmith, and Prometheus
* Streamlit interface and Docker-based development
* AWS deployment workflow

**Stack:** Python • FastAPI • LangGraph • Qdrant • Jina AI • PostgreSQL • Redis • RAGAS • NeMo Guardrails • AWS • Docker

🔗 **[Explore Perceptra on GitHub](https://github.com/Sunny914/Perceptra)**

### 2. 🛍️ ProductIQ — AI Fashion Search & Recommendation Engine

An AI-powered product discovery system designed to support natural-language search and recommendations across a fashion catalog of **367K+ products**.

**Key engineering areas:**

* Semantic retrieval using BGE embeddings
* Lexical search with BM25
* Hybrid candidate retrieval using Reciprocal Rank Fusion (RRF)
* Metadata-aware search and feature-based ranking
* Recommendations combining embedding, attribute, and lexical similarity
* Backend and frontend integration

**Stack:** Python • PyTorch • Transformers • Sentence Transformers • PostgreSQL • pgvector • BM25 • LightGBM • FastAPI • Next.js • Docker

🔗 **[Explore ProductIQ on GitHub](https://github.com/Sunny914/StyleIQ-AI-Fashion-Search)**

### 3. 🕸️ Research Paper Classification Using Graph Convolutional Networks

A graph-learning project that explores research-paper classification using paper features and citation relationships.

**Key engineering areas:**

* Graph construction from paper and citation data
* Node classification using Graph Convolutional Networks
* Neighborhood aggregation and graph-based feature learning
* Model training and evaluation
* Comparison with conventional machine-learning baselines

**Stack:** Python • PyTorch • PyTorch Geometric • NumPy • scikit-learn

🔗 **[Explore the GCN Project on GitHub](https://github.com/Sunny914/Research-Paper-Classification-using-Graph-Convolutional-Networks)**
